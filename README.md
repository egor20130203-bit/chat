# Scalable Chat — запуск

Личные сообщения, голосовые звонки, видео с камеры и демонстрация экрана
с пресетами качества (720p 60 / Full HD 120 / 2K 90 / 4K 60).

Фронтенд: React + Vite. Бэкенд: Supabase (база, аккаунты, реалтайм).
Звонки: WebRTC напрямую между устройствами.

---

## Шаг 1. Распакуй проект

Распакуй архив в `C:\chat2` — чтобы получилось `C:\chat2\package.json`.

## Шаг 2. Создай проект в Supabase

1. Зайди на supabase.com, войди через GitHub, нажми **New project**
2. Имя любое, пароль базы придумай и сохрани, регион — Frankfurt
3. Дождись, пока проект поднимется (пара минут)

## Шаг 3. Создай таблицы

В Supabase слева **SQL Editor** → **New query**.
Открой файл `supabase/schema.sql`, скопируй его содержимое целиком,
вставь в редактор и нажми **Run**. Должно написать «Success».

## Шаг 4. Пропиши ключи

В Supabase: **Project Settings** → **API**. Оттуда нужны две вещи:
`Project URL` и ключ `anon public`.

В папке `C:\chat2` создай файл `.env` (образец — `.env.example`):

```
VITE_SUPABASE_URL=https://твой-проект.supabase.co
VITE_SUPABASE_ANON_KEY=твой_anon_ключ
```

Через PowerShell это делается так:

```powershell
cd C:\chat2
notepad .env
```

Блокнот спросит про создание файла — соглашайся, вставь две строки, сохрани.

## Шаг 5. Запусти

```powershell
cd C:\chat2
npm install
npm run dev
```

Открой `http://localhost:8080`. Зарегистрируйся по email и паролю.

Если письмо с подтверждением не приходит — в Supabase зайди в
**Authentication → Sign In / Providers → Email** и выключи **Confirm email**.

## Шаг 6. Вход через Google (не обязательно)

В Supabase: **Authentication → Sign In / Providers → Google** → включить,
вставить Client ID и Secret из Google Cloud Console.
В настройках OAuth-приложения Google в Authorized redirect URIs добавить
адрес из подсказки Supabase.

## Как проверить звонок

Нужны два аккаунта. Открой сайт в обычном окне и в режиме инкогнито
(или на телефоне), зарегистрируй второй аккаунт.
В левой панели добавь контакт по email, со второго аккаунта прими заявку.
Дальше выбирай контакт и жми «Позвонить».

В окне звонка: микрофон, камера, демонстрация экрана и выбор качества.
Под своим видео показываются реальные разрешение и fps — по ним видно,
что фактически передаётся, а не что запрошено.

## Десктопное приложение

В `C:\scalable-chat\main.js` поменяй адрес на свой боевой сайт после
публикации, либо на `http://localhost:8080` для локальной проверки:

```js
const APP_URL = "http://localhost:8080";
```

Обработчик `setDisplayMediaRequestHandler` в `main.js` обязателен —
без него демонстрация экрана в приложении не заработает.

---

## Публикация в интернет (бесплатно)

1. Создай репозиторий на GitHub, залей туда папку
2. На vercel.com: **Add New → Project**, выбери репозиторий
3. В настройках проекта добавь переменные `VITE_SUPABASE_URL`
   и `VITE_SUPABASE_ANON_KEY`
4. Deploy — получишь адрес вида `имя.vercel.app`

Файл `.env` в репозиторий не попадёт, он в `.gitignore` — так и надо.

## Что стоит знать про качество

Звонок идёт напрямую между устройствами, без промежуточного сервера.
Поэтому качество упирается в исходящий канал того, кто транслирует:
Full HD — от 12 Мбит/с, 2K — от 18, 4K — от 30.

120 fps при захвате экрана браузеры обычно не отдают, потолок 60 —
пресет ставится, но фактический fps смотри в бейдже под своим видео.

Если один из участников за строгим NAT, прямое соединение может не
установиться — тогда нужен TURN-сервер. Скажи, если понадобится.
